# Working demonstration recording checklist

Record a 2–4 minute screen capture after the app works on your computer.

1. Show the project folder and briefly point out `app.py`, `services/`, `database/`, and `ui/`.
2. Start the app with `streamlit run app.py`.
3. Show the dashboard and MySQL connection status.
4. Open Live webcam, grant camera permission, and demonstrate live detection.
5. Upload a sample image and run detection.
5. Show bounding boxes, class labels, and confidence values.
6. Show the MySQL event history and export CSV.
7. Upload a short video and show the annotated output.
8. End by showing the README and GitHub repository page.

Before recording:
- Close unrelated apps and notifications.
- Use a sample image/video you have permission to use.
- Do not show `.env`, passwords, personal files, or private database information.
- Only claim features that you tested successfully.

Suggested title: “VisionTrack — YOLO Object Detection with OpenCV and MySQL”
